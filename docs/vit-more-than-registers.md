## 问题背景

Vision Transformers（ViTs）在大规模数据预训练后能够生成通用的视觉表示，在众多下游任务中表现优异。然而，在不同的监督范式（标签监督、文本监督、自监督）和下游任务中，ViT 的特征图普遍存在 **artifacts（伪影/异常激活）** 问题。已有工作对此现象的根因机制缺乏足够深入的解释。

---

## 核心发现：Lazy Aggregation 行为

本文通过系统分析，揭示了 ViT artifacts 的根本原因——**懒惰聚合（lazy aggregation）行为**：

- **现象**：ViT 倾向于将语义无关的背景 patch 作为"捷径"来表示全局语义，而非真正聚合有意义的前景特征。
- **驱动因素**：
  1. **全局注意力机制**：允许所有 token 无差别地相互交互，背景 patch 容易被当作"免费的"聚合对象。
  2. **粗粒度语义监督**：全局级别的监督信号（如分类标签）不足以引导模型区分前景与背景 patch 的语义贡献。

简而言之，ViT 偷懒地用背景 patch 来"凑数"完成全局表示，而非真正理解图像内容。

---

## 解决方案：选择性特征整合

作者提出了一种**选择性地将 patch 特征整合到 CLS token** 的方法：

- 核心思想是降低背景主导捷径对全局表示的影响，让 CLS token 更多地从有意义的前景 patch 中聚合信息。
- 该方法设计简洁，可直接应用于已有的 ViT 架构，无需大规模改造。

---

## 实验结果

在以下三种监督范式下的 **12 个基准测试**上，该方法均取得了**一致的性能提升**：

| 监督范式 | 示例任务 |
|----------|----------|
| 标签监督（Label-supervised） | 图像分类等 |
| 文本监督（Text-supervised） | CLIP 等多模态模型 |
| 自监督（Self-supervised） | DINO、MAE 等 |

---

## 主要贡献

1. **首次系统揭示** ViT 中 lazy aggregation 行为的本质机制，填补了对 artifacts 根因理解的空白。
2. **提出简洁有效的解决方案**，通过选择性特征整合消除背景捷径的影响。
3. **广泛的泛化验证**，证明该问题和解决方案在多种监督范式下具有普适性。
4. 为理解和改进 ViT 行为提供了**全新视角**。

---

## 个人备注

> 这篇论文的核心洞察是：ViT 的全局注意力 + 粗粒度监督 → 导致模型"偷懒"用背景 token 充当语义捷径 → 产生 artifacts。解决思路很直觉：在 CLS token 聚合时引入选择性机制，抑制无意义背景的贡献。
